    01

    Status in the menu bar菜单栏看状态メニューバーで状態を確認

    A ring counts running chats. A red badge counts finished, unread ones, with ! when one is waiting for you (to approve or answer, or it stopped on an error). An optional sound or voice says which chat is done.

    圆环里是在跑的对话数；红色角标是做完还没看的，带 ! 表示有对话在等你（要你确认或回答，或者出错停下了）。可以开提示音，或用语音说出是哪个对话做完了。

    02

    Chats as a map对话变成导图チャットをマップに

    03

    Colors and shapes颜色和形状カラーとシェイプ

    Questions常见问题よくある質問

    Is this made by Anthropic or OpenAI?这是 Anthropic 或 OpenAI 做的吗？Anthropic や OpenAI が作ったアプリですか？

    No. KIKUmap is an independent open-source project. It reads the Claude app's window through Accessibility, so a Claude or ChatGPT update can break parts of it until KIKUmap catches up.

    不是。KIKUmap 是独立的开源项目。它通过「辅助功能」读 Claude App 的窗口，所以 Claude 或 ChatGPT 改版后，部分功能可能要等 KIKUmap 更新才能恢复。

    いいえ。KIKUmap は独立したオープンソースプロジェクトです。アクセシビリティ機能で Claude アプリのウインドウを読み取っているため、Claude や ChatGPT のアップデートによって、KIKUmap が対応するまで一部の機能が動かなくなることがあります。

    What does it work with?支持哪些 App？何に対応していますか？

    The Claude desktop app, Claude Code (Terminal, VS Code, Cursor, the app's Code mode), the ChatGPT desktop app and Codex in VS Code or the terminal. Chats pinned in ChatGPT show running and unread. Codex chats are supported best (from the app's files, even with its window closed); other chats less well (from ChatGPT's window, while part of it can be seen). Not shown: anything running on another computer or in the cloud.

    Claude 桌面 App、Claude Code（终端、VS Code、Cursor、App 的 Code 模式）、ChatGPT 桌面 App，以及 VS Code 或终端里的 Codex。ChatGPT 里置顶的对话都能显示「在跑 / 未读」。Codex 对话支持得最好（读 App 的文件，窗口关着也准）；其他对话支持有限（读 ChatGPT 的窗口，窗口要露出一部分）。不显示：在别的电脑或云端运行的任何东西。

    Claude デスクトップアプリ、Claude Code（ターミナル、VS Code、Cursor、アプリの Code モード）、ChatGPT デスクトップアプリ、そして VS Code やターミナルの Codex に対応しています。ChatGPT でピン留めしたチャットは、実行中と未読を表示します。最もよく対応しているのは Codex のチャットです（アプリのファイルから読み取るため、ウインドウを閉じていても動作します）。それ以外のチャットは対応が限定的です（ChatGPT のウインドウの一部が見えている間、そこから読み取ります）。別のコンピュータやクラウドで実行中のものは表示されません。

    Claude's window is closed. What happens?Claude 的窗口关了会怎样？Claude のウインドウを閉じるとどうなりますか？

    ⌘W only hides it. KIKUmap reads Claude's chats from the window, so it waits until the window is back on the current desktop; running chats show "running?" meanwhile, and once it's back one found done says "done after 14:00", since when it finished isn't known. Claude Code and Codex chats aren't affected; ChatGPT's other chats are read from ChatGPT's window the same way.

    ⌘W 只是把窗口藏起来。KIKUmap 从窗口里读 Claude 的对话，所以要等窗口回到当前桌面；在那之前，在跑的对话显示「在跑？」，窗口回来后发现已经做完的显示「14:00 后做完」，因为不知道它具体什么时候做完。Claude Code 和 Codex 对话不受影响；ChatGPT 的其他对话也是这样从 ChatGPT 的窗口里读的。

    ⌘W はウインドウを隠すだけです。KIKUmap は Claude のチャットをウインドウから読み取るため、ウインドウが現在のデスクトップに戻るまで待ちます。その間、実行中のチャットには "running?" と表示され、ウインドウが戻ったときに完了していたチャットには "done after 14:00" と表示されます。いつ完了したかがわからないためです。Claude Code と Codex のチャットには影響しません。ChatGPT のその他のチャットも、同じように ChatGPT のウインドウから読み取ります。

    A session finished while I watched it. Why is it still unread?会话做完时我正看着它，为什么还是未读？見ている間にセッションが完了したのに、未読のままなのはなぜですか？

    KIKUmap marks a finished session read by itself only when the window in front can only be that session's: for Claude Code, its folder's window in VS Code or Cursor, or a terminal window whose title shows both its folder and claude; for Codex, its folder's window in VS Code. If another window or tab could be showing it too, such as another editor window on its folder or a folder above it, it stays unread. Codex sessions in a terminal stay unread too (KIKUmap can't tell which terminal runs them). Open it from KIKUmap, or select it and press ⇧⌘U, to mark it read.

    只有最前面的窗口只可能是这个会话的，KIKUmap 才会自己把做完的会话标为已读：Claude Code 是 VS Code 或 Cursor 里打开它文件夹的窗口，或者标题里同时有它的文件夹和 claude 的终端窗口；Codex 是 VS Code 里打开它文件夹的窗口。别的窗口或标签页也可能在显示它时，它保持未读，比如编辑器里另有窗口开着它的文件夹或上层文件夹。终端里的 Codex 会话也保持未读（KIKUmap 不知道它在哪个终端里跑）。在 KIKUmap 里打开它，或选中它按 ⇧⌘U，就标为已读。

    KIKUmap が完了したセッションを自動で既読にするのは、最前面のウインドウがそのセッションのものとしか考えられない場合だけです。Claude Code なら、VS Code や Cursor でそのフォルダを開いているウインドウ、またはタイトルにフォルダ名と claude の両方が表示されているターミナルウインドウ。Codex なら、VS Code でそのフォルダを開いているウインドウです。同じフォルダやその上位フォルダを開いた別のエディタウインドウなど、ほかのウインドウやタブにも表示されている可能性があれば、未読のままになります。ターミナルで実行中の Codex セッションも未読のままです（KIKUmap はどのターミナルで実行されているかを判別できません）。既読にするには、KIKUmap から開くか、選択して ⇧⌘U を押してください。
