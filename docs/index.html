A mind map for your Claude chats.给 Claude 对话的思维导图。

Kikumap lives in your Mac's menu bar and keeps track of every Claude chat: what's running, what's done, what needs your OK. Open it, and your pinned chats become a map you arrange yourself.

Kikumap 住在 Mac 的菜单栏里，帮你盯着每个 Claude 对话：哪个在跑、哪个做完了、哪个在等你批准。打开它，置顶对话就是一张由你自己整理的导图。

The 2-minute tour两分钟看懂

Narrated, with captions. It plays muted until you turn the sound on.

英文配音，带字幕。默认静音播放，点按钮打开声音。

Menu bar菜单栏

Know what Claude is doing随时知道 Claude 在干什么

One icon in the menu bar. The orange flower spins while a chat is running. A red badge counts chats that finished and you haven't read, with ! when one needs your approval.

Hear it instead of checking: a sound plays when a chat finishes or needs you, and Kikumap can then say which one ("Experiment plan is done") in the voice, speed and words you choose. Or use your own sound file.

菜单栏只有一个图标。橙色小菊花在转，就是有对话在跑；红色数字是做完了还没看的对话，带 ! 表示有对话在等你批准。

听声音就知道：对话做完或在等你时会响提示音，还可以接着念出是哪个对话（“实验计划做完了”），声音、语速、念的内容都能自己改，也可以换成自己的声音文件。

Works with the Claude desktop app and with Claude Code: Terminal, VS Code, and the app's Code mode.

支持 Claude 桌面 App，也支持 Claude Code（终端、VS Code、App 的 Code 模式）。

Mind map导图

Your chats, as a map对话变成一张导图

The left column mirrors the chats you pinned in Claude, in Claude's order, and your Claude Code sessions. The map starts empty: nothing goes on it until you put it there. Drag them onto your own topics: the item rides a live branch and the rest of the map slides aside to show where it will land. The map never rearranges itself on its own.

左栏是你在 Claude 里置顶的对话，顺序和 Claude 一样，还有你的 Claude Code 会话。导图一开始是空的，放什么由你决定。把它们拖到自己的主题下：拖动时节点带着实时连线跟着走，其他节点会让开，空出它要落下的位置。你不动，布局就不会自己变。

Several at once: drag a box on empty space (or ⌘/⇧-click), or ⌘/⇧-click in the left column, then drag any one of them. They all come along, in order. Hold space and move the mouse, or swipe with two fingers, to move around. Hide or resize the left column and the timeline (⌃⌘S, ⌃⌘T), and make everything bigger with ⌘+.

一次拖好几个：在导图空白处拖出选框（或 ⌘/⇧ 点击），或在左栏 ⌘/⇧ 点击，然后拖其中任意一个，选中的会按顺序一起过去。按住空格移动鼠标、或双指滑动，就能移动导图。左栏和时间线可以隐藏（⌃⌘S、⌃⌘T）或拖边缘调宽，⌘+ 让整个窗口变大。

Real conversations carry a small orange mark. Hover one for two buttons: open it in Claude, or mark it unread again (⇧⌘U) so it waits for you until you've opened it.

真正的对话前面有橙色小标记。鼠标停在上面会出现两个按钮：在 Claude 里打开，或者标回未读（⇧⌘U），在你真正打开之前一直提醒你。

Style样式

Make it yours按你的习惯整理

Right-click any topic for a branch colour and a shape: square, circle, triangle, diamond, cross or star. Colours flow down the branch, into the timeline and the menu.

右键任意主题，换分支颜色、选图形：方块、圆圈、三角、菱形、交叉、星星。颜色会顺着分支往下，时间线和菜单里也跟着用。

Tags标签

Tag anything什么都能打标签

Tags like In progress, Waiting on others or Slides. Pick them from the right-click menu, or drag one from the shelf straight onto a chat.

比如「进行中」「等别人」「幻灯片」。右键菜单里勾选，或者从左下角的标签栏直接拖到对话上。

Click a tag to highlight everything that has it; the rest of the map fades back. Click again to clear.

点一下标签，带这个标签的都会高亮，其他的淡下去。再点一下取消。

Keyboard键盘

Keyboard-first键盘就能搞定

Like a real mind-map app: ⇥ new subtopic, ⏎ sibling, ⌘↑↓ reorder, ⌘Z undo.

和专业导图软件一样：⇥ 新建子主题，⏎ 同级主题，⌘↑↓ 调整顺序，⌘Z 撤销。

Also ⌫ delete, ⌥. fold, ⌘F search, and a tap on space to open a chat in Claude.

还有 ⌫ 删除，⌥. 折叠，⌘F 搜索，轻按空格 在 Claude 里打开对话。

Timeline时间线

What ran, and what's next做过什么，接下来做什么

The strip at the bottom shows when Claude worked on each chat, in your branch colours; chats running at the same time get rows of their own. Hover a run to see how long it took.

底部的时间线显示 Claude 什么时候在做哪个对话，用你的分支颜色；同时在跑的对话各占一行。鼠标停在上面能看到用了多久。

Drag ahead to see what's coming: your scheduled tasks (with usage turned on), each with a live countdown. Click anything to open it.

往后拖，就能看到接下来要发生的事：每个计划任务（需开启用量）都带实时倒计时。点一下就能打开。

Export导出

Take everything with you全部带走

Tick topics and export every chat under them, pinned or not, one folder per chat:

勾选主题，下面所有对话（置顶的、没置顶的都算）一次导出，每个对话一个文件夹：

  • memory.md a hand-off summary Claude writes inside the chatClaude 在对话里写的交接总结
  • prompts.md · conversation.md
  • artifacts/ · attachments/

The export can keep itself up to date. Import starts a new pinned chat per folder, in a new Claude account for example, so you pick up where you left off.

导出可以自动保持最新。导入会为每个文件夹开一个新的置顶对话，比如换到新的 Claude 账号，也能接着做。

Stays on your Mac数据留在你的 Mac 上

Everything lives in ~/Library/Application Support/ClaudeConsole/. The only network requests are usage checks to api.anthropic.com, and only if you turn usage on. No sign-up, no tracking. And no surprise prompts: every macOS permission dialog comes after Kikumap has told you what it's for and you've clicked to go ahead.

所有数据都在本机 ~/Library/Application Support/ClaudeConsole/。唯一的网络请求是向 api.anthropic.com 查询用量，而且只在你开启用量功能之后。不用注册，没有统计追踪。也不会突然弹窗：每个系统授权弹窗，都会先告诉你要做什么，你点了同意才出现。

Claude Code sessionsClaude Code 会话

Install in a minute一分钟装好

  1. Download Kikumap.dmg下载 Kikumap.dmg

    Apple silicon or Intel, macOS 13 or later.

    Apple 芯片或 Intel，macOS 13 及以上。

  2. Drag it to Applications拖进「应用程序」

    Open the disk image and drag Kikumap onto the Applications folder.

    打开 DMG，把 Kikumap 拖到「应用程序」文件夹上。

  3. Allow the first launch允许第一次打开

    The app isn't notarized, so macOS blocks it once. Go to System Settings → Privacy & Security, scroll down and click Open Anyway.

    没有付费的苹果开发者签名，第一次会被拦住：去「系统设置 → 隐私与安全性」，往下滑，点「仍要打开」。

Prefer to build it yourself? Clone the repository and open Install.command. It compiles and signs on your Mac, so permissions survive reinstalls.

想自己编译？用 git 克隆仓库，打开 Install.command，在本机编译并签名，以后重装不用重新授权。

Questions常见问题

Is this made by Anthropic?这是 Anthropic 官方做的吗？

No. Kikumap is an independent open-source project, not made by or affiliated with Anthropic.

不是。Kikumap 是个人独立开发的开源项目，与 Anthropic 无关。

Why is it a beta?为什么是测试版？

The Claude app has no public API, so Kikumap reads its window through macOS Accessibility. When Claude changes its interface, parts of Kikumap may stop working until it's updated.

Claude App 没有公开接口，Kikumap 是通过 macOS「辅助功能」读它的窗口。Claude 改界面后，部分功能可能要等 Kikumap 更新才能恢复。

Does it work with Claude Code?支持 Claude Code 吗？

Yes: in Terminal, VS Code and the Claude app's Code mode. Click Connect and Kikumap adds its hooks to ~/.claude/settings.json, backing up the old file first.

支持，终端、VS Code 和 Claude App 的 Code 模式都可以。点「连接」后，Kikumap 会把 hooks 写进 ~/.claude/settings.json，原文件会先备份。

What if I close Claude's window with ⌘W?用 ⌘W 关了 Claude 的窗口怎么办？

That only hides it: Claude keeps running and still sends its "finished" notifications, so Kikumap still marks chats as done and plays its sound. The live "running" spinner reads Claude's sidebar, so it waits until the window is back. Claude Code sessions aren't affected.

Claude 的 ⌘W 其实只是把窗口藏起来，App 还在运行，做完的通知照常发出，所以 Kikumap 照样标记做完、照样响提示音。只有「进行中」的转圈要读 Claude 的侧边栏，要等窗口回来再更新。Claude Code 会话完全不受影响。

免费。MIT 开源协议，不用注册，没有付费版。觉得好用的话，可以请我喝杯咖啡。

What does the name mean?名字是什么意思？

Kiku (菊) is Japanese for chrysanthemum: the little orange flower that spins in your menu bar while Claude works. Kikumap is the map that grows out of it.

Kiku（菊）是日语里的菊花，就是菜单栏里那朵 Claude 干活时会转的橙色小菊花；Kikumap 就是从它长出来的导图。
